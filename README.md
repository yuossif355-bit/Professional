# Professional Academy

موقع أكاديمية بروفيشنال: كرة يد · كرة سلة · كرة طائرة.

- `index.html` — الموقع العام (الألعاب، التواصل، الحجز عبر واتساب). الرقم والعنوان والألعاب والمواعيد في `CONFIG` أعلى السكريبت.
- `admin/index.html` — سجل الاشتراكات (مين دفع ومين لسه كل شهر). البيانات بتتحفظ في متصفح صاحب الجهاز، ومعاها تصدير CSV ونسخة احتياطية JSON.
